# 热重载机制改动记录：llm config 指纹缓存 + pattern/plugin/channel re-import

日期：2026-09-10。测试 615 → 631（新增 test_reload 15 + 端到端冒烟验证）；
仅剩的 2 个失败（test_trace_events）属并行进行中的 trace-events 工作，
stash 隔离验证与本改动无关。

## 动机

- 每轮对话 R1 刷新都走 `load_config` → 读文件 + yaml 解析 + 校验，
  是纯浪费（配置 99.9% 时间没变）。
- pattern / plugin / channel 是注册表单例，改业务代码必须重启进程。

## 改动清单

### nexus/settings.py（config 缓存）
- `load_config`：按 resolved path 记 `(mtime_ns, size)` 指纹；命中返回
  缓存**深拷贝**，未命中才 `_parse_config_file`（读→校验→规范化，从
  load_config 拆出的无缓存内核）。解析失败不落缓存。
- 新增 `reload_config()`（强制重读）/ `invalidate_config_cache()`。

### host/reload.py（新文件，代码重载）
- 追踪：sys.modules 里 `apps.<pkg>.<mod>` / `atoms.executors.<mod>` 名
  下的已 import 模块（含 prompts 等非注册模块）；mtime 对比找变更。
- 重放序：`_replay_order` 按 AST import 边（含相对 import）拓扑排序。
- `_ReplaceMode`：重放窗口内打开 plugin/channel 注册表的
  `replace_on_conflict`（替换 + 清实例缓存），结束恢复严格模式。
- `reload_changed` / `reload_all`（+config 失效）/ `rebind_sessions` /
  `init_baseline` / `ReloadWatcher`（`NEXUS_RELOAD_WATCH=1` 轮询）。

### 注册表 / channel
- `nexus/registry/plugins.py`、`channels.py`：`replace_on_conflict`
  开关（默认 False，行为不变；True 时同名不同物 → 替换而非拒绝）。
- `nexus/channels/webhooks.py`：handler 每请求 `_live_spec(spec)` 活取
  registry 现值（注销后回落装配时 spec，不 500）。

### host
- `main.py`：`POST /api/v1/reload`（重载 + 会话重绑）；startup
  `init_baseline()`；`NEXUS_RELOAD_WATCH=1` 自启 watcher。
- `cli.py`：`/reload` slash 命令。

## 避坑记录（后续必读）

1. **sys.modules 插入序不能当依赖序**：import 机制在模块 body 执行
   **前**把模块插入 sys.modules——消费者（route）先于其 body import
   的依赖（prompts）插入。按插入序重放恰好反了，必须 AST 拓扑排序
   （`_module_imports` + 分层 Kahn，循环依赖退化为原序）。
2. **重放必须全量**（变更 ∪ 未变注册 ∪ 未变非注册）：`importlib.reload`
   不级联依赖，消费者只有自己重执行才绑定到被依赖者的新对象——
   prompts 变更靠 route 连带重放生效（test_reload_prompts_change_
   propagates_via_consumer 钉死）。
3. **不做 AST 注册谓词过滤追踪名单**：语法错文件过不了
   `module_registers` 的 ast.parse，按谓词丢弃恰好丢失最需要反馈的
   变更（正确行为：检测到 → 重放失败 → 告警 + 保持旧注册）。
4. **config 缓存返回深拷贝**：`_validate_pattern_llm` 会原地清空
   pattern_llm 的非法键，浅拷贝会污染缓存。
5. **APFS mtime 纳秒粒度**：同秒重写指纹必变（正常编辑天然检测）；
   测试"同指纹"场景需等长替换 + `os.utime(ns=...)` 精确恢复纳秒
   （`os.utime` 的秒参数会截断到整秒，不精确）。
6. **repo 外模块 reload 的两个前提**（测试桥 `_import_out_of_repo`）：
   直接父包 `__path__` 指向文件真实目录（reload 靠它重找 spec）；文件
   mtime 必须变化（pyc 缓存失效）——否则 reload 重执行旧字节码。
7. **channel router 冻结的只有 URL 和 payload_model**：FastAPI 在
   handler 前完成 body 校验，模型不能每请求换；其余全部活取。
8. **重载失败不刷 mtime 基线**：下次 reload 自动重试（文件修好即收编）。
